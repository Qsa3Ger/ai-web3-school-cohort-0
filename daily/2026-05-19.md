## What I Learned

### LLM（大语言模型）
- LLM 生成的是概率上合理的输出，不是天然可信的事实
- Token、Embedding、Transformer、Hallucination、Multimodal 五个核心概念
- 最小实践：用 RPC 拉取链上交易，区分"链上事实" vs "模型推断"

### Prompt（提示词）
- Prompt 是软约束，不是安全边界 → 真正的边界由代码和校验承担
- Instruction / Few-shot / Structured Output / Prompt Injection
- JSON 让模型输出变成机器可处理的结构化数据

### Context（上下文）
- 模型只能基于它看见的上下文行动
- Context Engineering：设计什么进上下文、怎么分层、怎么刷新
- Memory 不能替代实时授权
- Agent 上下文分层：指令层 → 任务层 → 事实层 → 知识层 → 记忆层
